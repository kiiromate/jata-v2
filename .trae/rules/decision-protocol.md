# Decision protocol

Before proposing a solution, do a quick check:
1. Restate the actual problem (not just the symptom)
2. List key constraints (time, architecture, security)
3. List up to 3 approaches with tradeoffs
4. Choose the 80/20 option that delivers value with low complexity

Standards:
- Prefer composition over inheritance
- Prefer explicit over implicit
- Question every new dependency; prefer native solutions when viable
- Optimize for developer velocity and future maintenance
